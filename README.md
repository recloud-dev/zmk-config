# Mriya: текст и агенты

ZMK-раскладка Mriya на 44 клавиши для русского и английского текста, редактирования и работы
с агентами в tmux. Откройте `docs/keymap-proposed.html`, выберите слой и посмотрите нажатия
и удержания. Например, удержание FN и нажатие J отправляет Meh+F1 — переход к ожидающему агенту.

```sh
open docs/keymap-proposed.html
sh config/host/install.sh
```

Результат установки: skhd глобально перехватывает агентские клавиши и выполняет команды tmux.
FN+P отключён и оставлен в резерве.
Установщик использует существующие скрипты AgentBar из `~/.tmux/scripts`, сохраняет резервные
копии изменяемых настроек с суффиксом `.mriya-backup` и подключает `~/.config/mriya/skhdrc`
через `.load` в `~/.config/skhd/skhdrc`. Работающий skhd перечитывает конфигурацию автоматически.
Для первого подключения выбора модели нужно перезапустить Codex CLI.
Установленные биндинги хранятся в `~/.config/mriya` и сохраняются при переключении веток репозитория.
Конфликтующие пользовательские биндинги Codex установщик
не перезаписывает: в этом случае `config/host/codex.toml` объединяется с ними вручную.

## Слои

| Доступ | Слой |
|---|---|
| Без удержания | QWERTY / ЙЦУКЕН, прямые ё/х/ъ, home-row modifiers |
| FN слева внизу или удержание левого Enter | F-клавиши и агенты |
| Удержание Space или правого Enter | SYM: цифры, операторы и пунктуация |
| Удержание Tab или Backspace | NAV: движение, выделение, редактирование |
| Крайний левый большой палец или удержание правого Esc | Мышь |
| Мышь + S / F / D | Скорость ×2 / ×4 / ×8 |
| NAV + удержание левого Enter | SETUP: Bluetooth, reset, bootloader |

Правый Shift под большим пальцем действует как sticky modifier: тап применяет Shift к следующей
клавише, удержание позволяет набирать с Shift. На буквенных модификаторах используются
позиционные hold-tap для противоположной руки; Hyper сохраняет назначения skhd.

Copy/paste/cut и обе пары скобок доступны через прежние combo на основном слое.
`D+F` набирает `=` без пробелов. Операторы с пробелами, `->` и `=>` доступны на SYM.
Все 25 combo показаны отдельными схемами и таблицей в `docs/keymap-proposed.html`.

Символы соответствуют ABC и обычной Russian в macOS: `BACKSLASH` даёт ё, `[` — х, `]` — ъ.
На SYM русская пунктуация подписана отдельно: Shift+7 — точка, Shift+6 — запятая.
Квадратные скобки и операторы с пометкой EN набираются при английском источнике ввода.

## Агенты в tmux

| Код | Клавиша на FN | Действие |
|---|---|---|
| Meh+F1 | J | К агенту, ждущему ответа |
| Meh+F2 | K | Список агентов |
| Meh+F3 | L | Назад в исходную панель; повторное нажатие возвращает к агенту |
| Meh+F4 | U | Живой монитор |
| Meh+F5 | I | Развернуть / свернуть панель |
| Meh+F6 | O | Codex: меню пресетов, затем `0` — выбор модели; Claude: выбор модели |
| Нет события | P | Резерв |
| Meh+F8 / Meh+F9 | ; / ' | Reasoning ниже / выше |

В Codex reasoning меняется штатными Shift+Down/Up. В Claude открывается выбор модели и меняется
effort стрелкой; выбор подтверждается Enter. Черновик запроса сохраняется.
Модель и reasoning обрабатываются только в панели с процессом `codex` или `claude`.
Команды не отправляются обычному shell. Биндинги skhd для запуска приложений сохраняются.
Meh — Ctrl+Alt+Shift. Прошивка добавляет эти модификаторы к F1…F9 для агентских команд.
Сочетания обрабатываются в `config/host/skhdrc`. Терминал не участвует в их перехвате.
Скрипт выбирает подключённый клиент tmux с наиболее поздней активностью и его активную панель.
При равной активности нескольких клиентов команда отменяется. Клиент можно указать явно:

```sh
~/.config/mriya/agent-keys.sh model /dev/ttys000
```

Установщик удаляет собственные подключения из Ghostty и tmux и освобождает прежние
терминальные биндинги, сохраняя посторонние настройки. FN+P не отправляет события.

## Отрисовка и проверка

```sh
brew install pipx librsvg
pipx install keymap-drawer==0.21.0
scripts/draw-keymap.sh
tests/host-keys.sh
```

Результат: обновлённые HTML, SVG и PNG в `docs/`; проверки переходов, маршрутизации команд
и повторной установки биндингов. Физическая геометрия берётся из `config/mriya.json`,
подписи — из `docs/keymap-proposed.yaml`.

Прошивка собирается GitHub Actions для `mriya_left//zmk` и `mriya_right//zmk`.
Для локальной сборки в подготовленном west workspace:

```sh
west build -s zmk/app -d build/left -b mriya_left//zmk -- -DZMK_CONFIG=/path/to/zmk-config/config
west build -s zmk/app -d build/right -b mriya_right//zmk -- -DZMK_CONFIG=/path/to/zmk-config/config
```

Файлы для прошивки: `build/left/zephyr/zmk.uf2` и `build/right/zephyr/zmk.uf2`.
